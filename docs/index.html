Notewright

A workspace where you and your AI agents build your knowledge base.

Notes, plans, specs and meeting notes live in one place, as plain Markdown files in a folder you choose. On the Mac, your agent runs in a terminal right inside the app and works on the same files, and every change shows up in the open note as it happens.

What it does

  • Live preview editing for Markdown, with tables, task lists, code and diagrams
  • A built-in terminal for Claude Code, OpenCode, Codex or Gemini CLI (Mac)
  • A change history for every note, with a diff and one click restore (Mac)
  • Scheduled jobs that run shell commands or agent prompts (Mac)
  • Search across all notes, and Siri and Shortcuts actions

Notewright is available for Mac, iPhone and iPad.
