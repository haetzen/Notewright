MarkMind

A Markdown editor for people who work with AI coding agents.

Your notes are plain Markdown files in a folder you choose. On the Mac, your coding agent runs in a terminal right inside the app and works on the same files, and every change shows up in the open note as it happens.

What it does

  • Live preview editing for Markdown, with tables, task lists, code and diagrams
  • A built-in terminal for Claude Code, OpenCode, Codex or Gemini CLI (Mac)
  • A change history for every note, with a diff and one click restore (Mac)
  • Scheduled jobs that run shell commands or agent prompts (Mac)
  • Search across all notes, and Siri and Shortcuts actions

MarkMind is available for Mac, iPhone and iPad.
